# GauRush website
GauRush is a Windows desktop editor for 3D Gaussian splats. This public GitHub Pages site introduces the product, demonstrates its workflows, and provides the installer.
## Audience and purpose
Creators working with static or animated Gaussian captures. Visitors should understand the workflow, see real application recordings, and find the Windows download.
## Product truth
- Formats: PLY, SPLAT, KSPLAT and SOG, including numbered-frame sequences.
- Inspect and play sequences, crop using volumes, lasso-clean stray splats, organize and transform objects, parent objects, animate crop volumes and export frames/sequences.
- Projects reference original source assets rather than embedding entire sequences.
- Windows x64 release 0.31.0, 92,378,226 bytes. Installer is unsigned.
