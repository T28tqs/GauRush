# GauRush — Experimental Website (Original Demos)

This release keeps the experimental technical/HUD styling, removes the hero promotional video entirely, and restores the **exact four original WebM demos and JPG posters** from `GauRush-main.zip`. The original `assets/icon.svg` remains unchanged.

## Videos

- `assets/view.webm` — View & Play
- `assets/crop.webm` — Crop Boxes
- `assets/lasso.webm` — Lasso Cleanup
- `assets/animate.webm` — Animate

The interactive workspace tabs still switch between these four recordings. The hero is now a static, lightweight technical background with centered typography and no promo video. Scroll reveal and floating animations remain in place.

Open `index.html` in a browser or serve this folder with `python -m http.server 8000`.

The Windows installer download link remains unchanged; check the GitHub Release exists before publishing.
