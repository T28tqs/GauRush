TOOLS INVENTORY

Clean up stray splats from a single capture or an entire sequence. Organize the scene, animate crop volumes, and export the result.

GauRush
Editing system

  • Import the whole scene

    Import PLY, SPLAT, KSPLAT, and SOG files, or numbered frame sequences. Combine multiple captures in one scene.

  • Refine with precision

    Lasso-select unwanted splats. Crop with boxes, spheres, cylinders, cones, or extruded lassos. Manage crop volumes in the layer system.

  • Build your scene

    Move, rotate, scale, duplicate, and parent Gaussian objects and crop volumes. Keep the scene organized in a clear hierarchy.

  • Work with motion

    Keyframe crop position, rotation, and size. Select multiple keys, adjust timing, and set interpolation in the timeline.

  • Export your result

    Export the current edited frame or an entire sequence, including SOG sequences. Save linked projects to pick up where you left off.

Projects link to your original source files, keeping the project file small.
